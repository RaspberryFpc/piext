PiExtRestorer – Help

Restore Raspberry Pi drives under Windows. Selectively restore the MBR, boot partition and Linux system partition.

Overview

PiExtRestorer is the Windows tool for restoring Raspberry Pi images created with PiExt.

The application restores selected components of a physical target drive. The MBR, boot partition and Linux system partition can be selected independently.

Administrator privileges required: Start PiExtRestorer using Run as administrator. This is required for the program to access physical drives and partitions directly.

Restorable components

MBR The first sector of the drive, containing the MBR boot code and partition table.
Boot partition The complete Raspberry Pi boot partition.
System partition The EXT-based Linux system partition. To restore it, PiExtRestorer uses either the base image or the combination of the base image and the selected differential image.
Other partitions Other partitions are not part of the restoration scope. PiExtRestorer will avoid modifying their data wherever possible. However, their preservation cannot be guaranteed in every case.

The expected Raspberry Pi partition layout is:

  1. Partition 1: Boot partition
  2. Partition 2: System partition

Requirements

  • A Windows system running PiExtRestorer.
  • PiExtRestorer must be run with administrator privileges.
  • A physical target drive with sufficient capacity.
  • The required base image and, if applicable, its corresponding differential image.
  • The MBR image and/or boot image, if these components are to be restored.
Important: A base image or a differential image must be selected before every restoration. This also applies if only the MBR or only the boot partition is to be restored.

Performing a restoration

  1. Start PiExtRestorer with administrator privileges.
  2. Select the physical target drive.
  3. Select the required base image or differential image.
  4. Select the components you want to restore: the MBR, boot partition and/or system partition.
  5. Check your selections and start the restoration.

Only the selected components are written. Components that are not selected are not restored during this operation.

Please check carefully: Before starting, check the selected target drive carefully. The restoration overwrites the data belonging to each selected component on that drive.

Restoring a base image

Select the required base image. If the system partition is to be restored, PiExtRestorer uses this image as the complete source image for the system partition.

The MBR image and boot image are only required if the corresponding component has also been selected for restoration.

Restoring a differential image

Select the required differential image.

To restore the system partition, both the original base image and the selected differential image are required. The differential image contains the changes relative to the base image. During restoration, the base image is applied first, followed by the selected differential image.

No additional differential images are required. Each differential image refers directly to the base image, not to a previous differential image.

To restore the MBR or boot partition, the corresponding current image files are only required if those components have been selected.

About the MBR

When restoring the MBR, the entire stored first sector, including the MBR boot code and partition table, is written to the target drive. This can change the target drive's partition layout. Existing partitions and their data may become inaccessible as a result.

Important notes

  • Carefully check the selected target drive before every operation.
  • The restoration overwrites the data belonging to each selected component.
  • Other partitions are not part of the restoration scope. Their data will be left untouched wherever possible, but their preservation cannot be guaranteed in every case.
  • The corresponding base image must be available when using a differential image.
  • A base image or differential image must also be selected when restoring only the MBR or boot partition.
  • When restoring the MBR, the entire stored first sector, including the partition table, is written. This may make other partitions inaccessible.
Recommendation: Keep an additional copy of your image files on an NTFS- or exFAT-formatted drive. This keeps the backups accessible both under Windows with PiExtRestorer and under Linux with PiExt, even if the original drive is damaged.
