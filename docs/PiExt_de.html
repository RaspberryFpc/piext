PiExt – Hilfe

Übersicht

PiExt ist ein Werkzeug zum Erstellen und Wiederherstellen von Raspberry-Pi-Backups. Es sichert nicht den gesamten Datenträger, sondern die für das System wesentlichen Komponenten.

PiExt unterstützt Image-Erstellung und Wiederherstellung unter Linux. Für Windows steht die separate Anwendung PiExtRestorer zur Wiederherstellung bereit. Beide Anwendungen werden gemeinsam in einem Release-Paket bereitgestellt.

Start mit Administratorrechten: PiExt muss immer mit sudo gestartet werden, damit das Programm direkt auf physische Laufwerke und Partitionen zugreifen kann.

Was wird gesichert?

MBR Erster Sektor des Datenträgers einschließlich MBR-Bootcode und Partitionstabelle.
Bootpartition Die vollständige Bootpartition.
Systempartition Die EXT-basierte Linux-Systempartition. Es werden nur aktuell belegte Dateisystembereiche gespeichert.
Andere Partitionen Sie gehören nicht zum Image-Umfang und bleiben bei der Wiederherstellung möglichst erhalten.

Erwartete Raspberry-Pi-Partitionsaufteilung:

  1. Partition 1: Bootpartition
  2. Partition 2: Systempartition

PiExt arbeitet mit vollständigen physischen Laufwerken als Quelle bzw. Ziel, sichert und restauriert aber nur MBR, Boot- und Systempartition.

Images erstellen

Über die grafische Oberfläche wählen Sie das Quelllaufwerk und den Zielordner. PiExt erstellt bei jedem Image-Erstellungsvorgang automatisch ein aktuelles MBR- und Boot-Image.

  • Das vorherige MBR-Image wird ersetzt.
  • Das vorherige Boot-Image wird ersetzt.
  • Ein vorhandenes Base Image und vorhandene Differential Images bleiben unverändert.
  • Das System-Image wird – abhängig vom Inhalt des Image-Ordners – als Base Image oder als neues Differential Image angelegt.
Wichtig: Quelllaufwerk und Sicherungsziel sollten auf unterschiedlichen physischen Datenträgern liegen. So vermeiden Sie, dass Sicherungsdaten das Quelldatensystem überschreiben.

ZSTD-Komprimierung

Boot-, Base- und Differential-Images werden mit Zstandard (ZSTD) komprimiert. Der Komprimierungsgrad kann in den Programmeinstellungen von 1 bis 19 eingestellt werden.

Stufe Auswirkung
1 Schnellste Komprimierung, größere Image-Dateien.
2–8 Abgestufter Kompromiss zwischen Geschwindigkeit und Dateigröße.
19 Langsamste Komprimierung,kleinere Image-Datei.

Eine höhere Stufe kann die Dateigröße reduzieren, benötigt aber mehr Zeit. Die Einstellung betrifft die Image-Erstellung; für die Wiederherstellung ist keine separate Komprimierungsstufe erforderlich. Das MBR-Image wird unkomprimiert als .img gespeichert.

Image-Typen und Dateinamen

MBR-Image

mbr_image_YYYY-MM-DD.img

Enthält den MBR einschließlich Partitionstabelle und wird unkomprimiert gespeichert.

Boot-Image

boot_image_YYYY-MM-DD.zst

Enthält die vollständige Bootpartition und wird mit ZSTD komprimiert.

Base Image

base_image_<drive>_YYYY-MM-DD.zst
Beispiel: base_image_sda_2026-09-28.zst

Enthält das Ausgangsabbild der Systempartition. Das erste System-Image in einem Image-Ordner wird als Base Image angelegt. Es dient als Grundlage für alle späteren Differential Images und wird nicht überschrieben.

Differential Image

diff-image_YYYY-MM-DD_<number>.zst
Beispiel: diff-image_2026-09-29_1.zst

Enthält Änderungen gegenüber dem ursprünglichen Base Image. Jedes Differential Image bezieht sich direkt auf dieses Base Image, nicht auf ein vorheriges Differential Image. Andere Differential Images werden zur Wiederherstellung eines ausgewählten Differential Image nicht benötigt.

Aufbau eines Image-Ordners

Image Folder/
|-- mbr_image_2026-11-05.img
|-- boot_image_2026-11-05.zst
|-- base_image_sda_2026-09-28.zst
|-- diff-image_2026-09-29_1.zst
`-- diff-image_2026-11-05_2.zst

MBR- und Boot-Dateien zeigen mit ihrem Datum die letzte Image-Erstellung. Base und Differential Images behalten ihre ursprünglichen Dateinamen und Erstellungsdaten.

Images wiederherstellen

Die Wiederherstellung erfolgt über die grafische Oberfläche von PiExt unter Linux oder PiExtRestorer unter Windows. MBR, Bootpartition und Systempartition können unabhängig voneinander ausgewählt werden.

Image-Auswahl ist immer erforderlich: Vor jeder Wiederherstellung muss ein Base Image oder ein Differential Image ausgewählt werden. Das gilt ausdrücklich auch dann, wenn ausschließlich der MBR oder nur die Bootpartition wiederhergestellt werden soll. Anschließend werden nur die angehakten Komponenten restauriert.

Base Image wiederherstellen

Wählen Sie das gewünschte Base Image. Das MBR-Image und das Boot-Image werden nur benötigt, wenn die jeweilige Komponente zur Wiederherstellung ausgewählt wurde.

Differential Image wiederherstellen

Wählen Sie das zum Differential Image gehörende Base Image und das gewünschte Differential Image. Wenn auch die Systempartition wiederhergestellt werden soll, werden beide Dateien benötigt. Für MBR und Bootpartition sind die jeweiligen aktuellen Image-Dateien nur erforderlich, wenn diese Komponenten ausgewählt wurden. Weitere Differential Images sind nicht erforderlich.

Wiederherstellung der aktiven Systempartition

Ein laufendes Linux-System kann seine eigene aktive Root-Partition nicht wiederherstellen. Starten Sie den Raspberry Pi dazu zunächst von einem anderen System bzw. Bootmedium. Alternativ können Sie PiExtRestorer unter Windows verwenden.

Hinweis zum MBR

Beim Wiederherstellen des MBR wird auch die gespeicherte Partitionstabelle geschrieben. Dadurch kann sich die Partitionsaufteilung des Ziellaufwerks ändern. Andere Partitionen können davon betroffen sein.

Kommandozeile

Die Kommandozeile unterstützt ausschließlich die Image-Erstellung. PiExt muss mit Root-Rechten gestartet werden.

Syntax

sudo piext <drive> <destination-folder>

Beispiel

sudo piext /dev/sda /media/pi/backup
  • <drive>: vollständiges physisches Quelllaufwerk, z. B. /dev/sda.
  • <destination-folder>: Ordner für die Image-Dateien. Er wird automatisch angelegt, falls er noch nicht existiert.

Es müssen genau zwei Parameter angegeben werden. Eine Wiederherstellung über die Kommandozeile ist nicht möglich. Auch die Komprimierungsstufe und gespeicherte GUI-Einstellungen können dort nicht festgelegt werden.

Rückgabewerte: 0 = erfolgreich, 1 = Fehler.

Kompatibilität und Voraussetzungen

  • Raspberry Pi mit Linux für PiExt.
  • Partitionstabelle im MBR-Format; GPT wird nicht unterstützt.
  • EXT2-, EXT3- oder EXT4-Systemdateisystem.
  • Root-Rechte für den direkten Zugriff auf physische Laufwerke.
  • Ausreichend Speicherplatz für die Image-Dateien.

PiExt-System-Images verwenden ein programmspezifisches Format und können nicht direkt mit Standardwerkzeugen wie dd wiederhergestellt werden.

PiExtRestorer benötigt Windows sowie Administratorrechte für die Laufwerkswiederherstellung.

Wichtige Hinweise

  • Prüfen Sie vor jedem Vorgang sorgfältig Quell- und Ziellaufwerk.
  • Quelllaufwerk und Sicherungsziel sollten unterschiedliche physische Datenträger sein.
  • Die Wiederherstellung überschreibt die Daten der jeweils ausgewählten Komponente auf dem Ziellaufwerk.
  • Andere Partitionen werden möglichst erhalten; dies kann nicht in jedem Fall garantiert werden.
  • Halten Sie das Base Image zusammen mit den dazugehörigen Differential Images verfügbar.
  • Bei jeder Image-Erstellung werden MBR- und Boot-Image aktualisiert.
  • Das Wiederherstellen des MBR schreibt auch die gespeicherte Partitionstabelle.
  • PiExt muss mit sudo gestartet werden.
  • Auch für eine reine MBR- oder Boot-Wiederherstellung muss ein Base oder Differential Image ausgewählt sein.
