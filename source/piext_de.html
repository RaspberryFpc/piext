PiExt

PiExt erstellt und stellt komprimierte Images von Linux- EXT2-, EXT3- und EXT4-Partitionen wieder her.

Das erste in einem Image-Ordner erstellte Image wird automatisch als Basis-Image erstellt. Weitere Images werden als differenzielle Images auf Basis dieses Basis-Images erstellt.

Quell- und Zielpartitionen

Für die Image-Erstellung muss eine Quellpartition ausgewählt werden.

Die Quellpartition ist die EXT2-, EXT3- oder EXT4-Partition, von der das Image erstellt wird.

Für die Wiederherstellung eines Images muss eine Zielpartition ausgewählt werden.

Die Zielpartition ist die Partition, auf die das ausgewählte Image wiederhergestellt wird.

Der Ordner für die Speicherung der Images wird unabhängig von der Quell- oder Zielpartition ausgewählt.

Image-Ordner

PiExt verwendet einen Ordner zum Speichern der Image-Dateien.

Für die Image-Erstellung muss ein Image-Ordner ausgewählt oder erstellt werden.

Für die Wiederherstellung muss der Ordner ausgewählt werden, der die benötigten Image-Dateien enthält.

Pro Image-Ordner ist nur ein Basis-Image zulässig.

PiExt vergibt die Dateinamen der Images automatisch. Ein Dateiname muss nicht manuell eingegeben werden.

Image-Speicherung

PiExt speichert nicht die vollständige Partition.

Es werden nur die belegten Sektoren des EXT-Dateisystems gespeichert. Nicht belegte Sektoren werden aus dem Image ausgelassen.

Dadurch wird die Menge der zu speichernden und zu verarbeitenden Daten deutlich reduziert, insbesondere wenn die Partition über einen großen Anteil freien Speicherplatzes verfügt.

Alle Images werden während der Erstellung direkt mit Zstandard (ZSTD) komprimiert.

Die erzeugten Image-Dateien verwenden die Dateiendung .zst.

Basis-Image

Das erste Image, das in einem leeren Image-Ordner erstellt wird, wird automatisch als Basis-Image erstellt.

Das Basis-Image enthält den ursprünglichen Zustand der EXT-Partition.

Beispiel:

base_image_sda2_2026-09-21.zst

Der Dateiname enthält die Quellpartition und das Erstellungsdatum.

Differenzielle Images

Jedes weitere Image, das im selben Image-Ordner erstellt wird, wird automatisch als differenzielles Image erstellt.

Ein differenzielles Image enthält die Änderungen gegenüber dem Basis-Image.

Beispiele:

diff-image_2026-09-21_1.zst
diff-image_2026-09-21_2.zst

Die Nummer wird für jedes neue differenzielle Image automatisch erhöht.

Differenzielle Images basieren direkt auf dem Basis-Image und sind nicht von anderen differenziellen Images abhängig.

Images wiederherstellen

Jedes Image im Ordner kann einzeln zur Wiederherstellung ausgewählt werden.

Basis-Image wiederherstellen

Wenn das Basis-Image ausgewählt wird, wird nur das Basis-Image benötigt. 

base_image_sda2_2026-09-21.zst

Differenzielles Image wiederherstellen

Wenn ein differenzielles Image ausgewählt wird, muss das zugehörige Basis-Image ebenfalls im selben Image-Ordner vorhanden sein.

Beispiel:

base_image_sda2_2026-09-21.zst
diff-image_2026-09-21_1.zst

Der Wiederherstellungsvorgang kombiniert das Basis-Image mit dem ausgewählten differenziellen Image. 

Basis-Image + Diff-Image 1 → wiederhergestellte Partition

Die anderen differenziellen Images werden für die Wiederherstellung nicht benötigt. Sie können gelöscht werden, wenn sie nicht mehr benötigt werden.

Jedes differenzielle Image kann daher unabhängig ausgewählt und wiederhergestellt werden.

Image-Struktur

Ein Image-Ordner kann beispielsweise folgende Dateien enthalten: 

base_image_sda2_2026-09-21.zst
diff-image_2026-09-21_1.zst
diff-image_2026-09-21_2.zst
diff-image_2026-09-21_3.zst

Die Struktur ist: 

Basis-Image
     |
     +-- Diff-Image 1
     +-- Diff-Image 2
     +-- Diff-Image 3

Jedes differenzielle Image verwendet dasselbe Basis-Image.

Einzelne differenzielle Images können gelöscht werden, wenn sie nicht mehr benötigt werden.

Das Basis-Image muss für alle differenziellen Images, die noch wiederhergestellt werden sollen, verfügbar bleiben.

Image-Kompatibilität

Das von PiExt verwendete Image-Format ist ein programmspezifisches Format.

Derzeit können mit PiExt erstellte Images nur mit PiExt wiederhergestellt werden.

Die .zst-Dateien sollten daher nicht als normale Festplatten-Images betrachtet werden, die beispielsweise mit Tools wie dd direkt auf ein Gerät geschrieben werden können.

Wichtig

  • Für die Image-Erstellung muss eine Quellpartition ausgewählt werden.
  • Für die Image-Wiederherstellung muss eine Zielpartition ausgewählt werden.
  • Es werden nur belegte Sektoren des EXT-Dateisystems gespeichert.
  • Alle Images werden während der Erstellung mit Zstandard komprimiert.
  • Das erste Image in einem leeren Ordner wird automatisch zum Basis-Image.
  • Pro Image-Ordner ist nur ein Basis-Image zulässig.
  • Alle nachfolgenden Images werden als differenzielle Images erstellt.
  • Differenzielle Images basieren direkt auf dem Basis-Image.
  • Ein differenzielles Image benötigt das Basis-Image für die Wiederherstellung.
  • Das Basis-Image muss verfügbar bleiben, solange differenzielle Images benötigt werden.
  • Einzelne differenzielle Images können gelöscht werden, wenn sie nicht mehr benötigt werden.
  • Jedes Image kann unabhängig ausgewählt und wiederhergestellt werden.
  • Die Dateinamen werden automatisch vergeben.
  • Die Images verwenden die Dateiendung .zst.
  • Die differenzielle Image-Erstellung ist für EXT2-, EXT3- und EXT4-Partitionen vorgesehen.
  • Images können derzeit nur mit PiExt wiederhergestellt werden.

Typischer Arbeitsablauf

Images erstellen

  1. Die Quellpartition auswählen.
  2. Den Image-Ordner auswählen oder erstellen.
  3. Das erste Image erstellen.
  4. Das erste Image wird automatisch zum Basis-Image.
  5. Änderungen am System vornehmen.
  6. Ein weiteres Image erstellen.
  7. Das neue Image wird automatisch als differenzielles Image erstellt.
  8. Den Vorgang bei Bedarf wiederholen.
  9. Differenzielle Images löschen, die nicht mehr benötigt werden.

Ein Image wiederherstellen

  1. Die Zielpartition auswählen.
  2. Den Image-Ordner auswählen, der die Images enthält.
  3. Das gewünschte Image auswählen.
  4. Die Wiederherstellung starten.
  5. Wenn ein differenzielles Image ausgewählt wurde, muss das Basis-Image ebenfalls im Image-Ordner vorhanden sein.

Das ausgewählte Image wird direkt auf der Zielpartition wiederhergestellt.

Die aktive Root-Partition wiederherstellen

Die aktuell laufende Root-Partition kann nicht wiederhergestellt werden, während das System von dieser Partition ausgeführt wird.

Um die aktive Root-Partition wiederherzustellen, muss der Raspberry Pi zunächst von einem anderen System oder einem anderen Boot-Medium gestartet werden.

Eine empfohlene Lösung ist eine separate SD-Karte oder ein USB-Stick mit einem minimalen Linux-System und einer minimalen Desktop-Umgebung, auf dem PiExt installiert ist.

Den Raspberry Pi von dieser SD-Karte oder diesem USB-Stick starten und PiExt vom separaten System ausführen. Die ursprüngliche Systempartition ist dann nicht mehr die aktive Root-Partition und kann wiederhergestellt werden.

Die Image-Dateien können auf einem anderen USB-Laufwerk, einem Netzwerkspeicher oder einem anderen zugänglichen Speichermedium gespeichert werden.

Nach Abschluss der Wiederherstellung den Raspberry Pi herunterfahren und anschließend erneut vom wiederhergestellten System starten.

Kommandozeilenparameter

PiExt kann auch über die Kommandozeile verwendet werden. Sobald mindestens ein Kommandozeilenparameter angegeben wird, arbeitet PiExt im CLI-Modus. Die grafische Oberfläche wird dabei nicht angezeigt. Nach Abschluss des Vorgangs wird PiExt automatisch beendet.

Parameter können entweder mit = oder durch ein Leerzeichen angegeben werden.

Beispiele:

--sourcepartition=/dev/sda2

oder:

--sourcepartition /dev/sda2

Image erstellen

Parameter Beschreibung
--create Startet automatisch die Erstellung eines Images.
--sourcepartition <partition> Gibt die Quellpartition an, von der das Image erstellt wird, z. B. /dev/sda2.
--createdestination <ordner> Gibt den Zielordner für das Image an. Existiert der Ordner nicht, wird er automatisch erstellt.
--destination <ordner> Gibt den Zielordner für das Image an. Der Ordner muss bereits existieren.
--compressionlevel <wert> Legt die Zstandard-Kompressionsstufe fest.
--lastsettings Verwendet die zuletzt gespeicherten PiExt-Einstellungen als Ausgangswerte. Explizit angegebene Kommandozeilenparameter überschreiben diese Einstellungen.

Image wiederherstellen

Parameter Beschreibung
--restore Startet automatisch die Wiederherstellung eines Images.
--sourceimage <datei> Gibt die Image-Datei an, die wiederhergestellt werden soll.
--targetpartition <partition> Gibt die Zielpartition an, auf die das Image wiederhergestellt wird, z. B. /dev/sda2.

Allgemeine Hinweise

--create und --restore starten den jeweiligen Vorgang automatisch.

Der Unterschied zwischen --createdestination und --destination besteht darin, dass --createdestination einen noch nicht vorhandenen Zielordner automatisch anlegt, während --destination einen bereits vorhandenen Zielordner voraussetzt.

--lastsettings kann zusammen mit den anderen Parametern verwendet werden. Explizit angegebene Kommandozeilenparameter haben Vorrang vor den gespeicherten Einstellungen.

Beispiele

Image erstellen und Zielordner bei Bedarf anlegen:

sudo piext --create --sourcepartition /dev/sda2 --createdestination "/media/pi/hzg2/Diff_image"

Image erstellen mit Kompressionsstufe 5:

sudo piext --create --sourcepartition /dev/sda2 --createdestination "/media/pi/hzg2/Diff_image" --compressionlevel 5

Image erstellen mit bereits vorhandenem Zielordner:

sudo piext --create --sourcepartition /dev/sda2 --destination "/media/pi/hzg2/Diff_image"

Image wiederherstellen:

sudo piext --restore --sourceimage "/media/pi/hzg2/Diff_image/base_image_sda2_2026-09-21.zst" --targetpartition /dev/sdd2

Gespeicherte Einstellungen verwenden und die Image-Erstellung automatisch starten: 

sudo piext --lastsettings --create

Rückgabewerte

Im CLI-Modus beendet sich PiExt nach Abschluss des Vorgangs automatisch.

  • 0 = Vorgang erfolgreich abgeschlossen
  • 1 = Fehler beim Vorgang
