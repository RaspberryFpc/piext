Übersicht

PiExtRestorer ist das Windows-Werkzeug zur Wiederherstellung von Raspberry-Pi-Images, die mit PiExt erstellt wurden.

Die Anwendung stellt die ausgewählten Komponenten eines physischen Ziellaufwerks wieder her. MBR, Bootpartition und Linux-Systempartition können unabhängig voneinander ausgewählt werden.

Administratorrechte erforderlich: Starten Sie PiExtRestorer über Als Administrator ausführen. Nur so kann das Programm direkt auf physische Laufwerke und Partitionen zugreifen.

Wiederherstellbare Komponenten

MBR Erster Sektor des Datenträgers mit MBR-Bootcode und Partitionstabelle.
Bootpartition Die vollständige Bootpartition des Raspberry Pi.
Systempartition Die EXT-basierte Linux-Systempartition. Für die Wiederherstellung wird das Base Image oder die Kombination aus Base Image und ausgewähltem Differential Image verwendet.
Andere Partitionen Andere Partitionen gehören nicht zum Wiederherstellungsumfang. Ihre Daten werden durch PiExtRestorer möglichst nicht verändert. Eine vollständige Erhaltung kann jedoch nicht garantiert werden.

Die erwartete Raspberry-Pi-Partitionsaufteilung lautet:

  1. Partition 1: Bootpartition
  2. Partition 2: Systempartition

Voraussetzungen

  • Windows-System mit gestarteter Anwendung PiExtRestorer.
  • PiExtRestorer muss mit Administratorrechten ausgeführt werden.
  • Ein physisches Ziellaufwerk mit ausreichender Kapazität.
  • Das benötigte Base Image und gegebenenfalls das zugehörige Differential Image.
  • Das MBR-Image und/oder Boot-Image, sofern diese Komponenten wiederhergestellt werden sollen.
Wichtig: Vor jeder Wiederherstellung muss ein Base Image oder ein Differential Image ausgewählt werden. Das gilt auch dann, wenn ausschließlich der MBR oder nur die Bootpartition wiederhergestellt werden soll.

Wiederherstellung durchführen

  1. Starten Sie PiExtRestorer mit Administratorrechten.
  2. Wählen Sie das physische Ziellaufwerk aus.
  3. Wählen Sie das gewünschte Base Image oder Differential Image aus.
  4. Aktivieren Sie die Komponenten, die wiederhergestellt werden sollen: MBR, Bootpartition und/oder Systempartition.
  5. Prüfen Sie Ihre Auswahl und starten Sie die Wiederherstellung.

Es werden ausschließlich die angehakten Komponenten geschrieben. Nicht ausgewählte Komponenten werden von diesem Wiederherstellungsvorgang nicht restauriert.

Bitte sorgfältig prüfen: Kontrollieren Sie vor dem Start insbesondere das ausgewählte Ziellaufwerk. Die Wiederherstellung überschreibt dort die Daten der jeweils ausgewählten Komponente.

Base Image wiederherstellen

Wählen Sie das gewünschte Base Image aus. Soll die Systempartition wiederhergestellt werden, verwendet PiExtRestorer dieses Image als vollständiges Ausgangsabbild der Systempartition.

Das MBR-Image und das Boot-Image werden nur benötigt, wenn die jeweilige Komponente ebenfalls zur Wiederherstellung ausgewählt wurde.

Differential Image wiederherstellen

Wählen Sie das gewünschte Differential Image aus.

Wenn die Systempartition wiederhergestellt werden soll, werden das ursprüngliche Base Image und das ausgewählte Differential Image benötigt. Das Differential Image enthält die Änderungen gegenüber dem Base Image. Bei der Wiederherstellung wird zunächst das Base Image und anschließend das ausgewählte Differential Image angewendet.

Weitere Differential Images sind nicht erforderlich. Jedes Differential Image bezieht sich direkt auf das Base Image und nicht auf ein vorheriges Differential Image.

Für die Wiederherstellung von MBR oder Bootpartition werden die entsprechenden aktuellen Image-Dateien nur benötigt, wenn diese Komponenten ausgewählt wurden.

Hinweis zum MBR

Beim Wiederherstellen des MBR wird der gesamte gespeicherte erste Sektor einschließlich MBR-Bootcode und Partitionstabelle auf das Ziellaufwerk geschrieben. Dadurch kann sich dessen Partitionsaufteilung ändern. Bestehende Partitionen und ihre Daten können dadurch unzugänglich werden.

Wichtige Hinweise

  • Prüfen Sie vor jedem Vorgang sorgfältig das ausgewählte Ziellaufwerk.
  • Die Wiederherstellung überschreibt die Daten der jeweils ausgewählten Komponente.
  • Andere Partitionen gehören nicht zum Wiederherstellungsumfang. Ihre Daten werden möglichst nicht verändert; eine vollständige Erhaltung kann jedoch nicht garantiert werden.
  • Für ein Differential Image muss das dazugehörige Base Image verfügbar sein.
  • Auch für eine reine MBR- oder Boot-Wiederherstellung muss ein Base Image oder Differential Image ausgewählt sein.
  • Beim Wiederherstellen des MBR wird der gesamte gespeicherte erste Sektor einschließlich Partitionstabelle geschrieben. Dadurch können andere Partitionen unzugänglich werden.
Empfehlung: Bewahren Sie Ihre Image-Dateien zusätzlich auf einem NTFS- oder exFAT-formatierten Datenträger auf. Dadurch bleiben die Sicherungen sowohl unter Windows mit PiExtRestorer als auch unter Linux mit PiExt zugänglich, selbst wenn das ursprüngliche Laufwerk beschädigt wird.
